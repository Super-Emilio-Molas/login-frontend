# Login Frontend - Glasmorphism Design

Un hermoso login moderno construido con HTML, CSS y JavaScript puro.

## Ver en Vivo

**[Abre el Login Aquí](https://super-emilio-molas.github.io/login-frontend/)**

## Características

### Diseño
- **Glassmorphism**: Efecto de vidrio translúcido moderno
- **Gradientes Animados**: Fondo dinámico que cambia cada 15 segundos
- **Animaciones Suaves**: Transiciones elegantes en todos los elementos
- **Responsive**: Funciona perfecto en móvil, tablet y desktop

### Funcionalidades
- **Validación en Tiempo Real**
  - Email: Validación de formato
  - Contraseña: Mínimo 6 caracteres
  - Checkmark verde al validar
  - Mensajes de error específicos

- **Interactividad**
  - Toggle para mostrar/ocultar contraseña
  - Botón submit con loader animado
  - Modal de éxito con animación
  - Recuerda email con localStorage

- **Extras**
  - Botones de login social (Google, GitHub, Microsoft)
  - Enlace "Olvidé mi contraseña"
  - Enlace a registro
  - Checkbox "Recuérdame"

## Stack Tecnológico

```
HTML5 - Estructura semántica
CSS3  - Animaciones y glassmorphism
JS    - Validación y interactividad
```
